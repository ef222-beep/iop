# IOP-Kartlegging App (Dybdeutvidelse)

Denne oppdaterte versjonen inneholder et langt mer nyansert og detaljert sett med kartleggingsoppgaver for matematikk og norsk på tvers av 2., 4., og 7. trinn.

## Nytt i denne versjonen:
1. **Flere faglige nyanser:** Appen fanger nå opp alt fra fonologisk bevissthet, algoritmisk tenkning (koding), økonomi/mynter, argumenterende skriving, og kildekritikk.
2. **Kategorisering (Tags):** Hvert eneste LK20-mål har fått en tilhørende faglig kategori (f.eks. "Brøkregning", "Tegnsetting", "Måling & Enheter") som gjør IOP-dokumentet lettere å strukturere for læreren.
3. **Målrettede SMART-tiltak:** Tiltakene som genereres er spisset ytterligere inn mot hva spesialpedagogikken krever (konkrete hjelpemidler, balansemodellen for algebra, visuelle skriverammer, etc).

For publisering til web, se tidligere instruksjoner: last filene opp til GitHub Pages. Alt kjøres 100% lokalt hos den enkelte lærer (GDPR-sikkert).
